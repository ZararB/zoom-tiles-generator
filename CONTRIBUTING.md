# Contributing

Keep this repository private unless its owner explicitly changes that decision.
Run Python and JavaScript tests before submitting changes. Add a reproducible
fixture and meaningful assertions for geometry or queue changes; preserve invalid
edit rejection, map-detail retention and artifact provenance.

Keep credentials, private project data, personal device/network settings, runtime
worlds, databases and model weights out of commits. Use public or clearly fictional
example data and retain upstream attribution. Do not enable public GitHub Pages,
public releases or internet-facing inference as part of routine development.

Open a normal issue or pull request for schema/contract changes. Document real
hardware and distinguish mocked contract tests, geometry tests, browser captures
and real GPU inference. Do not claim unmeasured speed or image quality.
